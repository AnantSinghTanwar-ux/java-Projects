# SimpleInventoryManager

A menu-driven inventory management system that allows you to manage items in a collection.

## Features
- Add new items to inventory
- View all items in inventory
- Update stock quantity of existing items
- Remove items from inventory
- Uses ArrayList (Java Collection) for storage

## How to Compile
```bash
javac SimpleInventoryManager.java
```

## How to Run
```bash
java SimpleInventoryManager
```

## Menu Options
1. **Add Item** - Add a new item with name, price, and quantity
2. **View All Items** - Display all items in a formatted table
3. **Update Stock** - Modify the stock quantity of an existing item
4. **Remove Item** - Delete an item from the inventory
5. **Exit** - Close the application

## Usage Example
```
Enter your choice (1-5): 1
Enter item name: Laptop
Enter item price: $999.99
Enter stock quantity: 5
Item added successfully!
```
