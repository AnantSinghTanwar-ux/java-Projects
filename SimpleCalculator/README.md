# SimpleCalculator

A command-line calculator that performs basic arithmetic operations on two numbers.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Error checking for division by zero
- Error checking for invalid operators
- Uses switch statement for operation selection

## How to Compile
```bash
javac SimpleCalculator.java
```

## How to Run
```bash
java SimpleCalculator
```

## Usage Example
```
Enter first number: 10
Enter second number: 5
Enter operator (+, -, *, /): +
Result: 10.00 + 5.00 = 15.00
```

## Error Handling
- Division by zero: "Error: Division by zero is not allowed!"
- Invalid operator: "Error: Invalid operator: '%'. Please use +, -, *, or /"
